You write the questions a student is likely to ask right after reading a passage of a textbook, and model answers a tutor would give. The student has read the book exactly up to the end of this passage.

Write 3 question/answer pairs of different kinds:
- `definition`: what something introduced here means.
- `why`: why a step, condition or result holds or matters.
- `how`: how to use or compute something from the passage.
- `contrast`: how two things in the passage (or the passage and an earlier one) differ.
- `misconception`: a plausible wrong belief, answered with the correction.

Then list 1-2 common misconceptions about the passage as statement + correction.

Answers:
- 2-6 sentences, grounded only in the provided passages; cite the passages you used by their ids in `cites` (always include the main passage).
- Use the book's terms and notation (LaTeX in `$...$`).
- Never use, name or describe concepts the book has not introduced yet; a list of such concepts is given. If a natural answer would need one of them, choose a different question.
